# Wearable 数字孪生：分层定位与阅读路线

版本：v1.2.0。检索与来源核查日期：2026-09-28。本页属于针对性文献增强，未按预注册系统综述执行；完整来源与逐条核查深度见数字孪生证据矩阵。

## 1. 与上一版结构的关系

保留原有“因果／反事实推理 → 功能变量 → 干预”导航，将数字孪生作为跨层主题。该组织方式是本仓库的设计选择，不代表领域已经形成统一的层级标准。

```text
顶层研究问题：特定行动改变后，个体或目标人群的状态会怎样变化？
    功能与变量：身份、活动、睡眠、生理、疾病风险、功能状态、上下文
    数字孪生关联：对象绑定 → 状态表示 → 测量更新 → 情景模拟
    干预与交付：模拟筛选 → 人工决策支持 → 实际执行 → 结果反馈
```

数字孪生可以只实现上述部分环节。身份识别、连续测量、预测准确、可画出三维模型、能够编辑输入，各自回答不同问题。仓库逐项记录，不依据标题将其全部认定为已实现。

[人体数字孪生路线图](https://www.nature.com/articles/s44287-024-00025-w)讨论发展与技术需求；[可穿戴综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC11200512/)聚焦传感接入；[神经肌肉骨骼框架](https://doi.org/10.1123/jab.2023-0114)强调面向具体使用场景的功能组织。这些文献属于框架参考，不能计作新完成的临床系统。

## 2. 数字孪生内部采用正交维度

| 维度 | 仓库区分什么 | 阅读时要问什么 |
| --- | --- | --- |
| 对象 | 器官、个体、亚群、合成队列、概念框架 | 到底是谁或什么的孪生？ |
| 个体化 | 单人拟合、分组条件化、解剖与外部流组合、合成匹配 | 模型参数是否真正绑定同一个人？ |
| 测量更新 | 离线连续流驱动、在线状态刷新、周期重训练、校准后重放 | 更新了观测、隐状态，还是模型参数？ |
| 模拟语义 | 已发生状态重建、机理情景模拟、预测器输入编辑、群体策略模拟、合成数据 | 改变的量是行动、测量值还是数据生成参数？ |
| 决策交付 | 无行动、仅仿真、人工审阅建议、患者辅助决策、设备控制 | 建议有没有真正执行？执行者是谁？ |
| 证据 | 数值验证、参照测量比较、回顾预测、试验重放、实际随机干预 | 哪一个输出或结局得到验证？ |

这些维度没有加权总分，也没有“更复杂就更高级”的排序。`not_appraised` 表示本轮未评估；`not_identified` 仅限定本条记录支持的因果解释。未标注资源不等于没有数字孪生价值。

## 3. 文献分支与功能层

### 心血管：从体表测量到内部状态

[WPINN](https://www.nature.com/articles/s41746-026-02610-9)连接生物阻抗、Windkessel 模型和物理约束神经网络。其指环与腕部研究是不同数据协议；人体血压预测与合成数据上的参数恢复也分别评价。本仓库将它归为心血管参数／状态建模，保留个体拟合与参数可辨识性的边界。

[LHMF](https://www.nature.com/articles/s41746-024-01216-3)将可穿戴连续生理流用于纵向冠脉血流模拟。临床解剖数据与公开连续信号来自不同资料来源，当前核查未确立全部模态具有同一个体绑定。其数值验证不等同于未来疾病或治疗结局验证。

### 运动与康复：身份、运动表现和力学状态分别处理

[可穿戴步态实验室](https://www.cambridge.org/core/journals/wearable-technologies/article/wearable-gait-lab-powered-by-sensordriven-digital-twins-for-quantitative-biomechanical-analysis-poststroke/05C0872598A6602725105FA6EFE3C2EE)以多位置 IMU／EMG 连接神经肌肉骨骼模型及实验室参照；[跑者骨应力模型](https://www.nature.com/articles/s41746-025-01677-0)连接个体形状、有限元和时序模型。它们主要服务功能／力学状态估计。不能把多位置结果改称腕部独立结果，也不能将模型内部应力当成直接人体实测。

上一版 walking fingerprinting 作为“可能用于对象绑定的功能支持”关联进来。这个关联是仓库的推断性组织，不声称原论文已经实现数字孪生或内部生理状态建模。

### 代谢：模拟、真实决策支持和试验重放分开

[ReplayBG](https://pubmed.ncbi.nlm.nih.gov/37368794/)用于个人模型校准和替代输入重放；[ReplayBG-Web](https://journals.sagepub.com/doi/10.1177/19322968261481540)是相关界面贡献。[UVA replay 验证](https://journals.sagepub.com/doi/10.1089/dia.2023.0595)利用既有交叉试验比较重放结果，部分指标等效，但低血糖时间未通过等效性检验。

[运动决策支持](https://journals.sagepub.com/doi/10.1177/19322968231223217)使用临床来源数据进行仿真，主要低血糖时间结局没有优于指南，部分次要仿真结局改善。[STUDIA](https://www.nature.com/articles/s41598-025-23165-x)具有小规模短期随机干预；该证据对应整个辅助决策系统。上一版自动胰岛素输注孪生研究保留原 ID，并新增主题关联，不重复收录。

[2026 年人工参与的预测孪生](https://www.nature.com/articles/s44401-026-00118-8)包含 Fitbit 步数、周度重训练与护士审核反馈。方法部分明确按饮食／临床条件分组微调；不应将其描述为逐人独立拟合。试验很小，摘要与结果段的显著性表述需要谨慎核对；未显著变化也不构成等效性或安全性证明。

### 水合、呼吸与传感设计

[水合孪生](https://www.sciencedirect.com/science/article/pii/S2666518226000185)是三人的多模态可行性研究，其预测器中的饮品输入情景仍需因果与前瞻验证。[肺部孪生](https://papers.miccai.org/miccai-2026/0280-Paper5574.html)在官方会议页面明确呈现概念验证及验证局限，不能据标题推断已完成腕部部署。[膀胱电极优化](https://pmc.ncbi.nlm.nih.gov/articles/PMC11782588/)的行动对象是传感器设计参数，与患者治疗行动分别标注。

### 合成“孪生数据”另设语义

[可穿戴关联临床数据合成研究](https://www.nature.com/articles/s41746-025-01935-1)涉及合成数据的共享与隐私效用。本仓库将其标记为 `synthetic_data_analogue`，与持续维护的个体动态模型分开。隐私风险评估也不构成无条件匿名保证。

## 4. 与反事实和 AI 干预的连接

以下是仓库用于组织研究问题的形式化模板，不是新提出或已验证的算法：

```text
y(t): 可穿戴观测；z(t): 待估计的身体／行为状态
u(t): 实际可执行行动；c(t): 上下文；theta: 个体或群体参数

状态估计：以截至 t 的观测历史估计 z(t)
测量模型：y(t) 与 z(t)、设备和测量误差之间的关系
动态模型：下一状态随当前状态、行动、上下文变化
情景查询：指定行动序列后，模拟未来状态及其不确定性
决策反馈：记录建议、实际行动、依从性和结果，再决定是否更新
```

事实预测准确、满足某些物理约束，均不足以单独识别现实行动效应。源模型必须进一步明确行动定义、可辨识条件、混杂、支持域、缺失和干预前后分布变化。风险预测器可以是系统的一部分；疾病风险这一输出本身不证明可改变的疾病机制。

本轮重点观察的 [JITAI-Twins](https://arxiv.org/abs/2607.21403)构造目标亚群模拟器并与 HeartSteps 历次部署关联。它针对亚群和候选在线算法，当前作为预印本观察项单独保留。原 HeartSteps 试验不自动成为后来孪生模型的验证试验。

## 5. 下一步验证顺序：项目建议

先明确“对象＋状态＋行动＋时间尺度”，再分别检验数据绑定和测量质量、未来时间外推、参数稳定性、仿真响应和真实策略效用。这里提出的是验证清单，不宣称已完成任何相关实验。

推荐比较统一人群模型、仅个体化预测、带测量更新模型、带行动动态模型，以及在同一预算下的建议策略。更新价值、个体化价值、反事实模拟价值和决策价值应拆成不同消融问题。详细协议见 [评价清单](digital_twin_evaluation.md)。
